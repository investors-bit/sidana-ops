Sidana Ventures · deal agents

What happens when an investor replies

Agent 1 sends the deal. Agent 2 reads every reply and does the next step. Agent 2 is two agents with the same rules: the Hot deals agent handles the 11 hot startups, the Deal flow agent handles everything else.

No reply is left unanswered

Every reply gets answered, or is marked as waiting on someone. Nothing waits more than 24 hours, and the oldest replies are handled first.

When the agents run

Every hour, Monday to Friday, 9 am to 7 pm IST, plus one run on Saturday and Sunday. Replies that come in overnight are handled in the first run the next morning.

When Aditya gets an email

Only when a meeting time is needed from the founder, or a trail mail needs his approval because there are no call notes.
